# Provas

Uma prova agrupa atividades de uma mesma turma e atribui uma quantidade de pontos a cada uma delas. A resolução de cada atividade continua usando o mesmo workspace, as mesmas tentativas e o mesmo fluxo de correção.

## Consultar as provas da turma

Abra uma turma e selecione a aba **Provas**. A lista permite pesquisar pelo título e ordenar pela data de vencimento.

Uma prova só aparece para estudantes quando possui uma data de início e esse horário já foi alcançado. A data de vencimento, quando definida, é exibida no cartão e nos detalhes.

## Resolver as atividades

Escolha **Iniciar Prova** para consultar as atividades vinculadas. Cada cartão pode mostrar quantos pontos a atividade vale dentro da prova.

As ações permanecem as mesmas das atividades avulsas:

- **Iniciar:** abre ou retoma o workspace;
- **Visualizar Resultados:** mostra o histórico de tentativas;
- **Responder Entrevista:** abre o questionário, quando disponível.

As tentativas pertencem à atividade. Abrir a mesma atividade pela aba **Tarefas** ou por uma prova não cria históricos separados.

## Consultar um gabarito

Quando o professor cria e libera um gabarito, a ação **Gabarito** aparece no cartão da atividade na aba **Tarefas**. O gabarito é somente leitura para estudantes e pode deixar de aparecer se a visibilidade for desativada.
